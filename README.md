# 모아두기 — 스크랩 & 할 일 웹앱

## 구글 로그인 · PC/모바일 데이터 동기화 (새로운 개발 단계)

Firebase Authentication(구글 로그인/로그아웃)과 Cloudflare Workers + D1(스크랩 DB/사이트 제목 조회) 연결 코드가 추가되어 있습니다. 실제 Cloudflare/Firebase 프로젝트 설정은 별도로 필요하며, 단계별 안내는 **[CLOUD_SETUP.md](CLOUD_SETUP.md)**와 **[worker/README.md](worker/README.md)**를 확인하세요.

연결 전에는 기존 로컬 저장 방식이 그대로 동작합니다. 구글 로그인 성공 후엔 계정별 D1 스크랩으로 전환되며, 이전 기기 스크랩은 **로컬 가져오기**를 눌러 명시적으로 추가할 수 있습니다. **↓ 백업 / ↑ 복원** 버튼은 JSON 파일로 서로 다른 브라우저 출처(`file://` ↔ GitHub Pages) 사이에서 기존 스크랩을 이동할 때 사용합니다. 기존 브라우저 저장 데이터를 자동 삭제하지 않습니다.

모바일에서 발견한 링크나 텍스트를 나중에 실행할 항목으로 관리하는 웹앱의 초기 디자인 시제품입니다.

## GitHub Pages에서 테스트

이 저장소는 HTML/CSS/JavaScript만으로 실행되는 프론트엔드 시제품입니다. `.github/workflows/pages.yml`에서 `main` 브랜치의 변경 사항을 자동 배포하도록 준비되어 있습니다.

1. GitHub에서 `moadoogi`라는 **Public** 저장소를 만들고, 로컬 프로젝트의 `main` 브랜치를 푸시합니다.
2. 저장소의 **Settings → Pages → Build and deployment → Source**를 `GitHub Actions`로 설정합니다.
3. **Actions**에서 배포 작업이 성공하면 `https://<GitHub ID>.github.io/moadoogi/`에 접속합니다.

**온라인 테스트의 제한:** 스크랩/태그/상태는 접속한 기기의 브라우저 `localStorage`에만 저장됩니다. PC에서 저장한 항목이 휴대폰에 자동으로 전달되지는 않습니다. Google Calendar 버튼은 일정 작성 화면만 열며, 자동 저장은 하지 않습니다. 안드로이드 공유 앱과 기기 간 동기화에는 별도 서버·DB가 필요합니다.

Python `title_server.py`와 Windows 배치 파일은 **로컬 전용 도구**입니다. GitHub Pages는 Python 서버를 구동할 수 없으므로 일반 사이트의 제목 자동 가져오기, X 게시물 본문 자동 수집, YouTube 임베드 중계는 온라인 버전에서는 동작하지 않습니다. 링크 열기와 스크랩·태그·메모 등 정적 기능은 사용할 수 있습니다. 공개된 사이트에는 실제 개인 메모가 포함되지 않으며, 시연용 데이터만 포함되어 있습니다.

## 실행

`index.html`을 크롬 또는 웨일 브라우저에서 열면 됩니다. 스크랩과 태그 저장은 서버 없이 동작합니다.

**게시글·유튜브 제목과 영상 미리보기는 `제목_자동가져오기.bat`로 실행하세요.** 기존 `index.html`을 열면서 로컬 제목 조회 및 YouTube 플레이어 서비스를 켭니다. 실행된 콘솔 창을 열어 두세요. 오류 153을 피하도록 로컬 서버의 플레이어 페이지에서 YouTube를 임베드합니다. 서버가 없거나 재생이 차단되면 원본 YouTube 링크로 볼 수 있습니다. 기존 브라우저 저장 데이터는 유지됩니다.

화면을 열 때 `style.css`, `improvements.css`, `composer.css`, `theme.css`, `app.js`, `assets/` 폴더를 함께 두어야 합니다.

## 빠른 붙여넣기 기능

1. **텍스트 입력창에 커서가 있을 때** Ctrl+V는 입력만 합니다. **스크랩** 버튼을 눌러 저장합니다.
2. **입력창 밖에서** Ctrl+V를 누르면 바로 관심에 저장합니다. 오른쪽 위 **붙여넣기 아이콘**도 클립보드를 읽어 즉시 스크랩합니다.
3. 일반 링크/텍스트/X/YouTube/GitHub/디시인사이드/아카라이브/코네를 자동 구분하고 사이트 종류를 일반 태그로 함께 저장합니다. 기존 항목에도 사이트 태그가 적용됩니다.
4. 한국어 날짜(예: 2026년 10월 21일, 10월 21일)와 시간대가 포함된 ISO 날짜는 한국시간 기준 날짜로 해석합니다.

5. 태그는 스페이스로 나눕니다. 입력된 태그를 누르면 삭제되며, 카드에서 검색과 수정이 가능합니다.

### 테마 · 태그 · 별표

- 화면 상단 달/해 아이콘으로 전체 라이트·다크 모드를 전환합니다. 선택값은 해당 브라우저에 저장됩니다.
- 카드나 상세 미리보기의 `#태그`를 클릭하면 상태에 관계없이 같은 태그를 가진 스크랩만 표시됩니다. **필터 해제**로 돌아갑니다.
- 등록창과 수정창에서 태그 뒤 **×**로 개별 삭제하고, 스페이스나 엔터로 태그를 구분합니다.
- 등록창과 카드·상세에서 별표를 설정하거나 해제할 수 있습니다. 별표 항목은 어떤 정렬에서도 위에 배치되며 같은 별표 그룹 안에서 드래그로 순서를 바꿀 수 있습니다.

클립보드 버튼은 브라우저 권한과 보안 정책에 따라 제한될 수 있습니다. 이때 Ctrl+V나 모바일 길게 누르기로 붙여넣으세요.

## 현재 동작하는 기능

- 샘플 스크랩 6개 제공
- 관심 클릭은 진행중으로 이동, 진행중·완료 클릭은 펼침 메뉴, 미루기·포기 클릭은 다음 상태로 이동
- 스크랩 추가 / 상세 화면에서 제목·상태 등 수정 / 삭제 / 완료 체크
- 상세 미리보기의 **내용 및 메모**를 그 자리에서 편집할 수 있으며 입력할 때마다 자동 저장됩니다.
- 검색과 왼쪽 손잡이 드래그 우선순위 변경, 최근 저장순 · 오래된 순 · 관련 날짜순 · 제목순 정렬
- 스크랩 목록은 처음 30개만 표시하며, 아래 **더 불러오기** 버튼으로 30개씩 추가 표시합니다. 검색·카테고리·태그·정렬 변경 시 처음 30개로 초기화됩니다. 모든 스크랩 데이터는 그대로 보관됩니다.
- 카드에서 상대 시간 표시, 상세 화면에서 KST 저장 시각 표시, 사용자 태그 저장 및 검색
- URL과 텍스트 동시 보관, 한국 시간대에서 날짜 해석
- 저장한 날짜가 있는 항목은 Google Calendar 일정 작성 화면으로 전달 (사용자가 최종 저장)
- 카드에는 한 개의 원본 주소 링크만 표시하고 상세 주소도 새 탭으로 열 수 있습니다. YouTube 로컬 서버 기반 재생 시도
- X 게시물 카드 제목은 우선 `@작성자`이며, 공개 게시물의 작성자 이름과 본문을 가져올 수 있으면 제목·메모로 보관해 카드에 **일반 텍스트**로 표시합니다. 상세 미리보기의 공식 X 위젯은 유지합니다.
- 브라우저 localStorage 보관 (해당 브라우저·기기 내에서만 저장됨)
- 반응형 모바일 디자인 및 공유 입력 시연

## 실제 서비스 개발 때 연결할 기능

- 안드로이드 공유 메뉴에서 링크·선택한 텍스트 받는 경량 APK (`ACTION_SEND`, `text/plain`)
- 웹앱과 APK가 동시에 접근할 서버 / 데이터베이스 / 사용자 인증
- 사이트 제목, 설명, 썸네일 등의 메타데이터 가져오기
- 일정 제목과 시간이 모호할 때 날짜 확인 UI
- X 게시물 접근 제한 및 삭제·비공개 대응
- 모바일에서 공유하면 즉시 서버에 저장되고 데스크톱에서 확인하는 동기화

이 문서는 시안 설명이며 백엔드, 안드로이드 공유 수신기, Google OAuth 자동 등록은 포함되어 있지 않습니다.
